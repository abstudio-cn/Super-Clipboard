# Super Clipboard 🐋

> **基于 WPF / .NET 8 的智能剪贴板 —— 让打字成为过去式**

一个运行在 Windows 系统托盘中的剪贴板增强工具。除了常规粘贴，它能**模拟键盘输入**逐字符"打字"到任何文本输入框——特别适合 NoVNC、KVM、远程桌面等**不支持剪贴板同步**的场景。

---

## ✨ 已实现功能

| 功能 | 说明 |
|------|------|
| 📋 剪贴板监控 | 实时捕获文本/图片/文件，自动记录 |
| ⌨️ 模拟键盘输入 | `Ctrl+Alt+V` 逐字符模拟打字，穿透一切远程桌面 |
| 📝 常规粘贴 | `Ctrl+V` 标准粘贴，不受影响 |
| 📜 历史记录 | 浏览、切换、预览所有复制过的内容 |
| ⭐ 收藏夹 | 将常用内容固定，重启后保留（注册表持久化） |
| 🌓 主题切换 | 支持亮色/暗色主题，跟随系统或手动切换 |
| 🪟 系统托盘 | 关闭窗口后后台运行，托盘图标一键唤出 |
| 🔒 单实例保护 | 互斥体防止重复启动 |
| ⚙️ 设置面板 | 自定义热键、分块大小、通知开关等 |

### 🚀 跨设备文件传输（无网络）

| 功能 | 说明 |
|------|------|
| 📤 文件发送 | 将任意文件编码为文本，通过键盘模拟逐字"输入"到远程设备 |
| 📥 文件接收 | 监听键盘输入，自动收集编码文本并解码还原文件 |
| 🗜️ 压缩模式 | **Deflate 压缩 + 自定义 Base93 编码**，减小传输体积 |
| 📦 非压缩模式 | **标准 Base64 编码**，兼容性最佳 |
| 🖥️ 解码命令生成 | 传输完成后自动生成对应平台的解码命令并复制到剪贴板 |
| 🪟 Windows 解码 | `typingTransfer decode`（压缩）/ `certutil -decode`（非压缩） |
| 🐧 Linux 解码 | `./typingTransfer decode`（压缩）/ `base64 -d`（非压缩） |
| 🔧 CLI 工具 | `typingTransfer.exe` — 独立的跨平台编解码命令行工具 |

## 🚀 快速开始

### 下载

从 [Releases](https://github.com/abstudio-cn/Super-Clipboard/releases) 下载最新版本。

### 使用

1. **解压运行** — 双击 `superClipboard.exe` 启动
2. **授权管理员权限** — 模拟键盘输入需要驱动支持，请点击"是"
3. **系统托盘** — 软件最小化到托盘（蓝色剪贴板图标🟦），双击打开主窗口
4. **开始使用**：
   - 正常复制内容 → `Ctrl+V` 普通粘贴
   - 需要模拟输入 → `Ctrl+Alt+V` 逐字符打字粘贴
5. **退出** — 右键托盘图标 → 退出

### 文件传输（跨设备）

1. 打开 **文件发送** 页面 → 选择文件 → 点击发送
2. 软件自动将文件编码为文本，通过键盘模拟逐字符"打"到远程设备
3. 传输完成后，选择接收方平台 → 解码命令自动复制到剪贴板
4. 在接收方终端粘贴并执行解码命令，还原文件

## ❓ 常见问题

**Q: 热键没反应？**
A: 可能是热键冲突。请到「设置」页面检查或修改热键。

**Q: 会收集隐私吗？**
A: 不会。软件完全离线运行，不上传任何数据。退出后剪贴板历史即清空（收藏内容存储在本地注册表）。

**Q: 支持哪些文件格式传输？**
A: 任意文件。软件将文件二进制数据编码为纯文本，在接收端解码还原。
