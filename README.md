# Super Clipboard 🐋

> **基于 WPF / .NET 8 的智能剪贴板 —— 让打字成为过去式**

一个运行在 Windows 系统托盘中的剪贴板增强工具。除了常规粘贴，它能**模拟键盘输入**逐字符"打字"到任何文本输入框——特别适合 NoVNC、KVM、远程桌面等**不支持剪贴板同步**的场景。

| 📋 剪贴板监控 | 实时捕获文本/图片/文件，自动记录 |

| ⭐ 收藏夹 | 将常用内容固定，重启后保留（注册表持久化） |
| 🌓 主题切换 | 支持亮色/暗色主题，跟随系统或手动切换 |
| 🪟 系统托盘 | 关闭窗口后后台运行，托盘图标一键唤出 |
| 🔒 单实例保护 | 互斥体防止重复启动 |
| ⚙️ 设置面板 | 自定义热键、分块大小、通知开关等 |
| 📖 功能说明页 | 内置完整功能说明：监听、历史、数字键粘贴、Excel 模式、文件收发、设置 |

| 功能 | 说明 |
|------|------|
| 📤 文件发送 | 将任意文件编码为文本，通过键盘模拟逐字"输入"到远程设备 |
| 📥 文件接收 | 监听键盘输入，自动收集编码文本并解码还原文件 |

| 🤖 自动收尾 | 传输完成后自动停止监听并解码，保存按钮直接可用 |

## 🚀 快速开始

### 下载

从 [Releases](https://github.com/abstudio-cn/Super-Clipboard/releases) 下载最新版本。

### 使用

1. **解压运行** — 双击 `superClipboard.exe` 启动
2. **授权管理员权限** — 模拟键盘输入需要驱动支持，请点击"是"
3. **系统托盘** — 软件最小化到托盘（蓝色剪贴板图标🟦），双击打开主窗口
4. **开始使用**：
   - 正常复制内容 → `Ctrl+V` 普通粘贴
   - 需要模拟输入 → `Ctrl+Alt+V` 逐字符打字粘贴
   - 需要粘贴历史内容 → 按下粘贴热键后 1 秒内按数字键选择（见下文「历史指定粘贴」）
5. **退出** — 右键托盘图标 → 退出

### 历史指定粘贴 🔢

按下任一粘贴热键（`Ctrl+V` 或 `Ctrl+Alt+V`）后，进入等待窗口（时长可在「设置 → 按键设置 → 历史粘贴等待时间」调整，200-2000ms，200ms 步进，默认 1 秒）：

| 操作 | 效果 |
|------|------|
| 按 `1` | 立即粘贴历史第 1 条（最新） |
| 按 `2` ~ `9` | 立即粘贴历史第 2~9 条 |
| 按 `0` | 立即粘贴历史第 10 条 |
| 什么都不按 | 等待窗口结束自动粘贴第 1 条 |
| 按其他键 | 取消本次等待，按键正常输入 |

- 小键盘数字键同样支持
- 历史条目顺序与「历史记录」页面一致（最新在前）
- `Ctrl+V` 模式将选中内容写入剪贴板后自动粘贴；`Ctrl+Alt+V` 模式直接模拟键入文本（无需剪贴板）

### 顺序/倒序粘贴 🔁

在「历史记录」页面工具栏点击模式按钮，循环切换：**开启列表粘贴 → 顺序粘贴 → 倒序粘贴**（再点回到初始状态）。标题栏会同步显示当前模式（如「超级剪贴板（顺序粘贴模式）」）。

开启后，每次按下粘贴热键（`Ctrl+V` 或 `Ctrl+Alt+V`）不再弹出数字选择，而是直接粘贴队列中的下一条，指针自动推进并循环：

| 模式 | 粘贴顺序 |
|------|---------|
| 顺序粘贴 | 从最新条目开始（列表第 1 条）→ 第 2 条 → ... → 最旧 → 循环 |
| 倒序粘贴 | 从最旧条目开始（列表最后 1 条）→ ... → 最新 → 循环 |

- 切换模式时以当时的历史列表为快照，粘贴期间新增/删除历史不影响本次队列
- 适合依次粘贴多个已复制的片段（如批量填写表格、多行代码等）
- 需恢复手动数字选择粘贴时，切换回初始状态即可

### Excel 编辑模式 📊

复制 Excel 单元格时，剪贴板会同时携带文字（TSV）与图片两种格式。默认情况下图片会出现在列表最前，导致粘贴出图片。

在「设置 → 剪贴板设置」开启 **Excel 编辑模式** 后：

1. 复制内容后等待 **1 秒**，确保剪贴板所有格式完全写入
2. 若发现复制的内容先是文字后是图片，**文字保持在列表最前**（图片仍保留在其后）
3. 此时粘贴热键优先粘贴文字内容，适合 Excel 编辑场景

无需打开设置页时，可直接按快捷键 **Ctrl+Alt+E** 开关此模式（快捷键可在设置页修改）。

### 文件传输（跨设备）

**发送端**：

1. 打开 **文件发送** 页面 → 选择文件 → 设置分块大小与编码方式 → 点击发送
2. 软件自动将文件编码为文本，通过键盘模拟逐字符"打"到远程设备（10 秒倒计时后开始）
3. 发送中可暂停/继续，点「取消」立即中止；进度条显示已发送块数

**接收端**：

1. 打开 **文件接收** 页面 → 选择接收模式（需与发送端一致：Base93 压缩 / Base64 / 原始文本）→ 点击「开始监听」
2. 自动捕获键盘输入的数据流，实时显示：分割块计数、字符数（已接收/总数）、剩余时间估算
3. 传输完成后自动停止监听、解码并还原原文件名，点「保存文件」另存到任意位置

**「发送（无软件本体）」模式**：纯 Base64 传输，接收方无需安装本软件；传输完成后选择接收方平台，解码命令自动复制到剪贴板，在接收方终端执行即可还原文件。

#### 传输协议 📡

- **传输头**：前 20 位为分割块总数、20~100 位为字符总数（不足前补 0），末尾为分割块提示符 `<!@@@@@@@!>`；接收端识别后自动删除并转换为计数
- **块分隔符**：每个数据块后跟一个 `<!@@@@@@@!>`，接收端自动剥离并计数
- **文件名标识**：所有数据发送完毕后附带 `<@@@filename@@@>` + 文件名（UTF-8 + Base64 编码），接收端解码还原原文件名

## ❓ 常见问题

**Q: 热键没反应？**
A: 可能是热键冲突。请到「设置」页面检查或修改热键。

**Q: 会收集隐私吗？**
A: 不会。软件完全离线运行，不上传任何数据。退出后剪贴板历史即清空（收藏内容存储在本地注册表）。

**Q: 支持哪些文件格式传输？**
A: 任意文件。软件将文件二进制数据编码为纯文本，在接收端解码还原。
